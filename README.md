# PasteDeck について — はじめにお読みください

このリポジトリには、コピーの履歴をさかのぼって貼り付けられる Mac アプリ「**PasteDeck**」が入っています。

メニューバー（画面右上）に常駐する小さなアプリで、**⇧⌘V**（メニューから変更できます）を押すと画面の下からカードが並んだ履歴パネルがスライド表示されます。過去にコピーしたテキスト・リンク・画像・ファイルの中から選んで Enter を押すだけで、直前まで使っていたアプリにそのまま貼り付けられます。

- 履歴はすべて **Mac の中だけ** に保存されます（`~/Library/Application Support/PasteDeck/`）。クラウド同期や外部送信は一切ありません
- **テキスト / リッチテキスト / HTML / リンク / 画像 / ファイル** に対応。書式付きでコピーしたものは書式ごと貼り付けられます（⇧Enter でプレーンテキストにもできます）
- パネルを開いてそのまま文字を打てば **インクリメンタル検索**。コピー元のアプリ名でも絞り込めます
- 履歴の保持は **件数上限**（100 / 500 / 1000 / 無制限）と **保持期間**（24 時間 / 1 週間 / 1 ヶ月 / 無期限）をメニューから変更できます。初期設定は **500 件・無期限** です
- パネルを開くショートカットは、メニューバーの **「ショートカットを変更…」** から好きなキーの組み合わせに変更できます
- よく使うものは **ピン留め**（⌘P）しておけば、どの保持設定でも消えません。**⇧⌘P** を押すとピン留めしたものだけに絞り込めるので、定型文をすぐ取り出せます
- 同じ内容をもう一度コピーしても重複せず、先頭に並び直すだけです
- 1Password などのパスワードマネージャーがコピーする **秘匿データは履歴に残しません**
- 画像はサムネイル、ファイルは Finder と同じ **Quick Look プレビュー** 付きのカードで表示されます
- **⌘E で履歴のテキストを編集**できます（誤字の修正・不要な部分の削除・URL のパラメータ削りなど）。**保存すると書式は破棄され、プレーンテキストになります** — クリップボードは同じ内容の書式付き版も別に持っており、片方だけ書き換えると「Word に貼ると直したはずの誤字が残る」という食い違いが起きるためです。書式が失われる場合は編集画面で事前に警告が出ます
- **⌘E でスクリーンショットに描き込めます**。道具は **ペン・黒塗り・矢印・トリミング** の 4 つで、**1〜4** のキーでも切り替えられます。編集中はパネルが広がって大きく表示され、**⌘Z** で 1 手ずつ取り消し、**⌘↩** で保存、**esc** で中止です。保存すると履歴の画像そのものが置き換わります（件数は増えません）。Retina の解像度は保たれるため、貼り付け先で大きさが変わることはありません
- Excel や Word からコピーしたテキストは、**コピー元の書式を反映してカードに表示**されます（文字色・太さ・大きさ・フォント・下線・セルの塗りつぶし）。貼り付ける前に「どのセルをコピーしたか」がひと目で分かります。カードに収まるよう文字の大きさは調整され、ライト／ダークどちらでも読めるように配色を補います

## 動作環境

- macOS 14 (Sonoma) 以降（macOS 26 Tahoe で開発・動作確認）
- ビルドには **Command Line Tools だけで OK**（フル Xcode は不要です）

## 技術スタック

| 領域 | 使用技術 |
|------|----------|
| 言語 / ビルド | Swift 6（言語モード v5）+ Swift Package Manager。外部依存ゼロ |
| UI | SwiftUI（履歴パネル・カード）+ AppKit（`NSPanel` / メニューバー常駐） |
| クリップボード監視 | `NSPasteboard` の `changeCount` を 0.25 秒間隔でポーリング（macOS に変更通知 API がないため） |
| グローバルホットキー | Carbon `RegisterEventHotKey`（初期値 ⇧⌘V・変更可） |
| 自動貼り付け | `CGEvent` で ⌘V キーストロークを前面アプリへ送出（要アクセシビリティ権限） |
| パネル表示 | フォーカスを奪わない `.nonactivatingPanel` な borderless `NSPanel` + `NSHostingView` |
| 永続化 | JSON インデックス + バイナリ plist（UTI → Data 辞書）のファイル保存 |
| サムネイル | `QuickLookThumbnailing`（ファイル）/ `NSImage`（画像）+ `NSCache` |
| 画像編集 | SwiftUI `Canvas`（描いている最中のプレビュー）+ `CGContext`（保存時にフル解像度へ適用）。座標変換は `PasteCore` の純粋関数に集約 |
| 重複判定 | CryptoKit の SHA-256 によるコンテンツハッシュ |
| テスト | 依存ゼロの自作テストランナー（CLT に XCTest が同梱されないため） |
| 配布形態 | `.app` バンドルを手組み + ad-hoc 署名（ローカル利用専用） |

## 導入手順

1. リポジトリを取得して、ビルドスクリプトを実行します:

```bash
git clone https://github.com/wataru-1016/PasteDeck.git
cd PasteDeck
./scripts/build-app.sh
```

2. 「完了: build/PasteDeck.app」と出たら、できたアプリを**アプリケーションフォルダ**に移動します（この場所に置くと「ログイン時に起動」も設定できるようになります）:

```bash
cp -R build/PasteDeck.app /Applications/
open /Applications/PasteDeck.app
```

3. 起動するとメニューバーにアイコンが現れます（Dock には出ません）。これで準備完了です

## 初回だけ必要な設定

- **アクセシビリティの許可**: パネルで項目を選んで Enter を押すと、初回だけ許可を求めるダイアログが出ます。**システム設定 > プライバシーとセキュリティ > アクセシビリティ** で「PasteDeck」を ON にしてください（選んだ内容を ⌘V キーストロークとして前面アプリに送るため、この許可が必要です）
- 許可するまでの間も、選んだ内容はクリップボードにコピーされるので、手動で ⌘V すれば貼り付けられます

## 使い方

1. 何かをコピーする（テキストでも画像でもファイルでも OK）
2. **⇧⌘V** を押してパネルを開く
3. ← → で選ぶ、または文字を打って検索
4. **Enter** で貼り付け（ダブルクリックでも OK）

| キー | 動作 |
|------|------|
| ⇧⌘V | パネルの表示 / 非表示（グローバル・メニューから変更可） |
| ← → | カードの選択移動 |
| Enter | 選択項目を貼り付け |
| ⇧Enter | プレーンテキストとして貼り付け |
| ⌘P | 選択項目のピン留めの切り替え |
| ⇧⌘P | ピン留めした項目だけを表示 / 全件に戻す |
| ⌘⌫ | 選択項目を削除 |
| esc | パネルを閉じる |
| 文字入力 | そのまま検索 |
| ⌘E | 選択項目のテキストを編集（⌘↩ で保存 / esc で取り消し） |
| ⌘A / ⌘C / ⌘X / ⌘V / ⌘Z | 検索欄・編集欄での全選択・コピー・カット・貼り付け・取り消し |

日本語入力の変換中は、Enter（変換の確定）・← →（変換範囲の調整）・esc（変換の取り消し）が入力方式側へ渡ります。変換を確定したあとに押すと、上の表のカード操作になります。

メニューバーのアイコンからは、監視の一時停止・履歴の保持設定（件数上限・保持期間）・未ピン履歴の消去・ログイン時起動の設定ができます。

## うまくいかないとき

- **Enter を押しても貼り付かない** → アクセシビリティ権限を確認してください。**リビルドした後は権限が無効になることがあります**（ad-hoc 署名のため）。システム設定でトグルを一度 OFF → ON し直せば直ります
- **⇧⌘V で別アプリの「ペーストしてスタイルを合わせる」が使えなくなった** → PasteDeck がこのキーを全体で使うためです。メニューバーの「ショートカットを変更…」から別の組み合わせに変更してください
- **「ログイン時に起動」が設定できない** → `/Applications` など安定した場所に置いた `.app` から起動している必要があります
- **履歴を完全に消したい** → アプリを終了してから `~/Library/Application Support/PasteDeck/` を削除してください

## 開発者向け

```bash
swift run PasteDeck             # .app を作らず直接実行
swift run PasteCoreTestRunner   # コアロジックのテスト（46 件）
```

アイコンはコードで描画しています。[scripts/generate-icon.swift](scripts/generate-icon.swift) を編集 → 1024px PNG を生成 → `sips` で各解像度に縮小 → `iconutil` で `Resources/AppIcon.icns` に変換、という流れで差し替えられます。

```text
Sources/
├── PasteCore/            # AppKit 非依存のコアロジック（テスト対象）
│   ├── ClipboardItem.swift   # モデル定義
│   ├── CaptureRules.swift    # 取り込み判定・種別判定・ハッシュ
│   ├── HistoryStore.swift    # 履歴管理（重複排除・上限・ピン留め）
│   ├── Persistence.swift     # JSON インデックス + plist 実データの永続化
│   ├── HotkeyShortcut.swift  # ショートカットの値・表示・妥当性判定
│   └── SearchFilter.swift    # インクリメンタル検索
└── PasteDeck/            # アプリ本体
    ├── main.swift
    ├── AppDelegate.swift
    ├── ClipboardMonitor.swift    # NSPasteboard ポーリング
    ├── PasteService.swift        # 書き戻し + ⌘V 送出（CGEvent）
    ├── HotkeyManager.swift       # グローバルホットキーの登録・差し替え（Carbon）
    ├── HotkeyPreferences.swift   # ショートカットの永続化（UserDefaults）
    ├── StatusBarController.swift # メニューバー常駐
    ├── Settings/                 # ショートカット設定ウィンドウ（キー記録）
    └── Panel/                    # 画面下スライドパネル（SwiftUI + NSPanel）
```

秘匿データの除外は、パスワードマネージャー各社が採用する `org.nspasteboard.ConcealedType` / `TransientType` / `AutoGeneratedType` マーカーの検出によって行っています。
